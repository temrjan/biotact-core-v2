# Пересборка шаблона трудового договора (PR-B) — гайд автору

Цель: пересобрать `td_osnovnoy` так, чтобы нумерация разделов шла подряд (в т.ч. **«2. ФУНКЦИИ,
ОБЯЗАННОСТИ И ПРАВА РАБОТНИКА»**) и узбекская/русская части были **параллельны по пунктам**. Юридический
текст должен остаться **1:1**. Авторинг — в MS Word (человек); эти скрипты дают чеклист и машинную проверку.

## Что понадобится
- Текущий шаблон `.docx` (боевой — на bcv2, `data/hr_templates/`). Он же — источник истины по тексту.
- Python-окружение проекта (`.venv`).

## Шаг 1. Экстракт текущих пунктов (чеклист)
```bash
python -m biotact.modules.hr.tooling.td_extract path/to/td_template.docx --out td_clauses.md
```
`td_clauses.md` — все пункты UZ|RU по позиции. **Колонки НЕ совпадают 1:1** (у языков разное число пунктов);
строки-дырки помечены `GAP-*`. Реальное спаривание UZ↔RU и разбор дырок — **юр-решение человека**, не скрипта.

## Шаг 2. Сборка в Word (правила целевой структуры)
- **Одна таблица**, **строка = один пункт**, две колонки: **UZ | RU** (как в оригинале: RU — «ТРУДОВОЙ
  ДОГОВОР», UZ — «МЕҲНАТ ШАРТНОМАСИ»).
- Внутри ячеек — **плоский текст, без вложенных таблиц**.
- Нумерация — **один многоуровневый список** (Word: «Многоуровневый список»): разделы `1…12` (lvl0), под-
  пункты `X.Y` (lvl1), `X.Y.Z` (lvl2). Номера **генерирует Word автоматически** — **не печатать цифры
  текстом** (`«2. »` руками — запрещено), не переопределять «начать с…».
- **Плейсхолдеры `{{ … }}`** — дословно, тот же набор, что в оригинале (скрипт сверит).

## Шаг 3. Машинная проверка
```bash
python -m biotact.modules.hr.tooling.td_verify path/to/td_template.docx path/to/candidate.docx
# опц.: --empty-rows 3,7   # индексы строк, где пустая ячейка ЛЕГИТИМНА (ратифицированный список)
```
Скрипт проверяет 4 вещи и печатает `OK`/`FAIL` по каждой:
1. **text_1to1** — тело каждого пункта совпадает с оригиналом (номера игнорируются; но если в кандидате
   номер напечатан текстом — падёт);
2. **placeholders** — набор `{{ }}` == оригинал;
3. **numbering** — один чистый многоуровневый список (ноль зашитых стартов/литералов-цифр);
4. **structure** — одна таблица, строка=пункт UZ|RU (ноль вложенных таблиц; пустые ячейки — только из
   `--empty-rows`).
Доводить кандидат до **всех четырёх `OK`**.

## Шаг 4. Визуальная приёмка в живом Word
Открыть в MS Word, убедиться: разделы идут `1,2,3,…,12` (в частности **«2. ФУНКЦИИ…»**), колонки
параллельны по строкам. Сделать скриншот (before/after).

## Шаг 5. Публикация
Загрузить готовый `.docx` как **новую версию** шаблона через HR-библиотеку (категория `td_osnovnoy`).
Старая версия остаётся — откат одним действием (`rollback_template`).
